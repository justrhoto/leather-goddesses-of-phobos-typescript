# Leather Goddesses of Phobos

Infocom's 1986 interactive fiction by Steve Meretzky, ported to TypeScript from
its original ZIL source and playable in the browser.

The game logic is not emulated: every routine, object and room of the original
was translated into TypeScript, and the result behaves the same as the released
game (release 59). See [PORTING.md](PORTING.md) for how that was checked.

## Playing

```sh
npm install
npm run dev        # then open the printed URL
```

`npm run build` produces a static site in `dist/` that can be hosted anywhere.

In the browser:

- Type commands in plain English (`north`, `take the flashlight`, `put jar in basket`).
  Up and down arrows recall earlier commands.
- **Undo** (or Ctrl+Z, or typing `undo`) takes back the last turn, as often as you like.
- The game is saved automatically after every turn, so closing the tab loses nothing.
- Save and load named positions from the menu, or type `save` and `restore` as in the original.
- When the story asks you to scratch a spot on the Scratch 'n' Sniff card, the card appears on screen.
- `tame`, `suggestive` and `lewd` set how racy the descriptions are, exactly as in the original.

To play in a terminal instead: `npm run play` (add `-- --seed 42` for a repeatable game).

## How it's built

```
reference/zil/     the original ZIL source (from the historicalsource archive)
tools/zil2ts/      the translator that turned the ZIL into TypeScript
src/game/          the game, in TypeScript (generated by the translator)
src/engine/        the runtime the game runs on: objects, tables, parser I/O, turns
src/ui/            the browser interface
tests/             a complete winning playthrough, plus engine and parser tests
tools/verify/      checks against the original compiled game: data tables, and transcripts
                   diffed against the original story file running on a test Z-machine
```

**`src/game/`** is the port itself: one module per original source file
(`parser.ts`, `verbs.ts`, `mars.ts`, …) with the same routines under TypeScript
names (`V-TAKE` → `vTake`, `ACCESSIBLE?` → `isAccessible`) and the same logic,
line for line. Objects and rooms are declared next to their action routines,
as in the original. `world.ts` holds the vocabulary, numbering and globals.

These files are generated. To change the game, change the translator or its
hand-written overrides (`tools/zil2ts/overrides.ts`) and run `npm run translate`,
so the port stays reproducible from the original source.

**`src/engine/`** provides what ZIL programs expect of their machine:

- `object.ts` – the object tree (parent/sibling/child), attribute flags and property tables.
- `table.ts` – ZIL tables with byte and word addressing and pointer arithmetic, holding
  real TypeScript values (objects, dictionary words, strings, routines).
- `runtime.ts` – ZIL's primitives: `TELL`, `READ` and its tokenizer, `EQUAL?`, `RANDOM`, and so on.
- `machine.ts` – runs the game one input at a time. ZIL code asks for input from deep
  inside routines (death prompts, yes/no questions), so the machine snapshots the world at
  the start of each turn and, when more input arrives, deterministically replays the turn
  with the answers queued. The same snapshots provide undo, save and restore.

## Tests

```sh
npm test
```

The suite plays the whole game to a winning finish (top rank, full score)
under five random seeds, and exercises undo, save/restore, restart and the parser.

`npm run walk` prints the winning playthrough's transcript
(`npm run walk -- 3 --then "inventory; score"` appends commands).
